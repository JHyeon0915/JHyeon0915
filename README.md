<h2>🔭 I'm currently working on ...</h2>

<h3>Feline Purrfect 🐱</h3>

* A daily behavior and health tracker for cat owners. It analyzes log data, surfaces possible health concerns, and has a fun breed finder.
* **Mobile:** React Native, Expo, Nativewind, TypeScript
* **Backend (fully rewritten):** ASP.NET Core (.NET 10), EF Core, SQL Server, custom JWT auth
* **AI:** Gemini API integration plus a RAG pipeline built on embeddings
* **Cloud & DevOps:** Docker, Azure Container Apps, Bicep (IaC), GitHub Actions CI/CD with OIDC
* **Next up:** a UI redesign, an LLM + RAG symptom assistant that logs for you, and monthly health reports
* Repo: [https://github.com/Feline-Purrfect/Feline-Purrfect](https://github.com/Feline-Purrfect/Feline-Purrfect)

<h2>🔭 I've worked on ...</h2>

<h3>CalmTrace</h3>

* A multimodal stress detection and intervention app, built as my MACS capstone at Dalhousie University under Dr. Rita Orji
* Combines live EEG data from an EMOTIV headset with HRV from a Garmin watch, and uses a DCNN-LSTM fusion model with SHAP explanations to give transparent, explainable predictions instead of an opaque score
* Includes an AI coaching chat powered by the Gemini API, with breathing, grounding, and reflection exercises
* Flutter (iOS / Android / macOS), FastAPI, TensorFlow, MongoDB, Firebase Auth, Figma
* Repo: [https://github.com/JHyeon0915/CalmTrace)](https://github.com/JHyeon0915/CalmTrace)

<h3>Care Bridge</h3>

* A doctor-centric health consultation web app built with a 4-person Agile team
* I worked across the stack, building REST APIs in Node.js and the React frontend, and cut page load time by 60% while closing 3 security gaps
* React.js, TypeScript, Node.js, AWS
* Repo: [https://github.com/JHyeon0915/CareBridge](https://github.com/JHyeon0915/CareBridge)


<h3>DALScooter</h3>

* I built the **3-factor authentication module** (AWS Cognito, Lambda, DynamoDB) and the **message passing module** (AWS SQS)
